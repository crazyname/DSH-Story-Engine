# 图形化内容包管理页面

## 启动

```powershell
pwsh -File D:\DSH-Story-Engine\manager.ps1
```

浏览器访问 `http://127.0.0.1:3091`。关闭运行窗口或按 `Ctrl+C` 会停止页面服务。

## 操作流程

1. 页面首先显示当前可用内容包和诊断错误。
2. 在“内容包文件夹”中填写包含 `pack.json` 的目录。
3. 点击“先校验”只检查内容，不复制文件。
4. 点击“校验并安装”会进行安全复制，并自动生成 DSH 游戏入口。
5. 如果手工调整了内容包，可以点击“重新生成游戏入口”。
6. 重启 DSH 后，新建对话时选择对应内容包。

## 安全边界

- 服务固定监听 `127.0.0.1`，不会对局域网开放。
- 写操作拒绝来自其他网页 Origin 的请求。
- 请求体最大 64 KiB。
- 静态页面使用内容安全策略，不加载外部脚本、字体或图片。
- 内容包安装继续使用 v0.3 的路径、链接、文件数量和总体积限制。
- 安装不会覆盖同 ID 的内置或现有内容包。
