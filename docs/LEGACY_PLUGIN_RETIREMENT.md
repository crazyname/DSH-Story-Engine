# 旧 Dispatch 插件退役与清除规则

旧项目：`D:\Dispatch-Harness-Plugin`

## 当前状态

旧插件已在用户明确要求下于 v0.2 后清除。本文件以下门槛保留为历史决策记录；不再执行旧插件迁移，也不尝试重建或恢复其商业游戏资料。

## 进入归档的必要条件

只有以下条件全部满足，才把旧目录改名为带日期的只读归档：

1. 新引擎达到 `v0.3`。
2. 通用插件能在 DSH 中独立启动。
3. 内容检索、人物资料、选择界面、状态提交和检查点达到旧插件功能对等。
4. Dispatch 私有内容包转换完成，记录数与关键档案数量核对通过。
5. 至少一个旧存档完成迁移预演和回滚测试；未通关期间可以使用人工测试存档代替真实存档。
6. 旧目录已生成压缩备份和 SHA-256 校验清单。
7. 用户亲自完成一次新版本验收并同意归档。

归档名称建议：`D:\Dispatch-Harness-Plugin.archive-YYYYMMDD`。

## 允许永久清除的必要条件

归档后继续保留至少 14 天。期间必须满足：

- 新引擎连续使用没有发现必须依赖旧插件的问题。
- 备份可以成功解压，并通过 SHA-256 校验。
- 私有 Dispatch 内容包和迁移报告仍完整可读。
- 用户再次明确授权永久删除。

没有第二次明确授权时，归档可以长期保留，但不得自动删除。永久删除只针对旧插件代码目录；原始游戏、Steam 文件、用户存档和独立备份不在清除范围内。

## 回退条件

发现记录缺失、存档不兼容、主持规则退化、检查点无法恢复或 DSH 装载失败时，立即停止退役流程，恢复旧插件为对照基线，修复后重新计算 14 天观察期。
